# 🚀 Minimal & Smart Vanilla JS Todo App

> **Vanilla JS만을 사용하여 구현한 미니멀하고 생산성 높은 캘린더형 Todo 웹 앱 인터페이스**
>
> 본 프로젝트는 외부 라이브러리나 프레임워크를 일절 배제하고 오직 브라우저 순수 API와 자바스크립트 기본 문법만을 사용하여 설계된 프론트엔드 과제 결과물

---

## ✨ 핵심 기능 (Key Features)

### 1. 기본 미션 달성 완료 (Core CRUD)
- **완성도 높은 데이터 제어**: 할 일 생성(Create), 목록 실시간 렌더링(Read), 텍스트 수정(Update), 제거(Delete) 메커니즘 구축 완료
- **엄격한 예외 처리 및 유효성 검증**: 빈 입력값 제출 시 경고 알림 노출 및 프로세스 차단 처리 구현 완료
- **체계적인 완료 상태 토글링**: 체크박스 선택에 따른 인라인 취소선 적용 및 시각적 디바이스 다크닝 처리 완료

### 2. 고도화된 상태 필터링 매트릭스 (Status Filtering)
- **실시간 필터링 스위치**: '전체(All) / 진행 중(Active) / 완료(Completed)' 세 가지 상태의 인터랙티브 필터 탭 레이아웃 설계 완료
- **동적 UI 바인딩**: 현재 활성화된 필터 탭에 포커스 하이라이트 배경색(#672be0)을 동적으로 래핑하는 CSS 클래스 스위칭 메커니즘 탑재 완료

### 3. 일간 & 도전 미션: 주간 달력 뷰 확장 (Weekly Dynamic Calendar)
- **주차별 타임라인 바인딩**: 월요일부터 일요일까지 7일 주기의 가로형 주간 캘린더 인터페이스 구현 완료
- **무한 타임라인 이동**: `<` 및 `>` 네비게이션 버튼 터치 시 정확히 7일 간격으로 이전/다음 주차 달력이 자동 계산 및 업데이트 처리 완료
- **날짜별 메타 데이터 카운팅**: 각 날짜 카드 하단에 해당 일자에 등록된 총 할 일 개수를 실시간 집계하여 정수형 배지로 인디케이트 처리 완료
- **오늘 날짜 독립 하이라이팅**: 시스템의 현재 날짜를 실시간 감지하여 특수 점선 테두리 스타일 및 고유 컬러 시스템으로 독립 시각화 완료

### 4. 무중단 데이터 보존 (LocalStorage Sync)
- **데이터 영속성 확보**: 투두 레코드의 변경사항 발생 즉시 브라우저 로컬스토리지에 데이터 자동 싱크 처리 완료
- **정교한 직렬화 메커니즘**: JSON.stringify 및 JSON.parse를 통한 데이터 구조 직렬화 및 역직렬화 완벽 적용 완료
- **고유 식별자 무결성 보장**: 새로고침 시 기존 데이터의 최대 ID값을 스캔하여 인크리멘탈 ID 중복 이슈 완벽 방지 처리 완료

## 🚀 실행 및 로컬 환경 구동 방법 (How to Run)

본 앱은 파일 시스템 경로 직접 접근(file://) 대신 로컬 웹 서버 환경에서 구동하는 것을 권장함

1. **VS Code** 에디터 실행 후 `todo-vanilla` 작업 폴더 개방함
2. 좌측 탐색기에서 `index.html` 선택 후 마우스 우클릭 수행함
3. **Open with Live Server** 명령 클릭하여 실행함
4. 브라우저 창 활성화 및 로컬 호스트 포트 자동 연결 후 앱 사용함
